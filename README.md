# University-Hostel-Management-System
A complete University Hostel Management System built using **PHP**, **MySQL**, **HTML/CSS**, and **JavaScript**, supporting Admin, Student, and Staff operations.

---

## 📌 Features  
### 👨‍💼 Admin  
- Manage students, staff, and rooms  
- Allocate rooms  
- View payments and refunds  
- Assign maintenance tasks  
- Approve roommate requests  
- Track visitors  
- Generate and manage shifts  
- View attendance  

### 👩‍🎓 Students  
- Login and view dashboard  
- Submit maintenance requests  
- Make payments  
- Request refunds  
- Request roommate changes  
- Update personal information  
- Register visitors  

### 👷 Staff  
- View assigned tasks  
- Mark attendance  
- Handle maintenance requests  
- View shift details  

---
## 🛠️ Technologies Used  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server:** Apache (XAMPP)  

---

## 🚀 How to Run the Project  
1. Install **XAMPP** 
2. Move the project folder into:  
   ```
   htdocs/hostel-management   (for XAMPP)  
   ```
3. Start **Apache** and **MySQL**  
4. Import `hostel_management.sql` into phpMyAdmin  
6. Open in browser:  
   ```
   http://localhost/hostel-management/
   ```
